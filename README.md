# SafeTurnPredictor

Safe Turn Predictor is an AI-powered driver assistance application that analyzes vehicle speed and road curvature to determine whether an upcoming turn can be navigated safely.

## Features

- Road curvature detection
- Safe speed calculation
- Real-time warnings
- Dashcam video analysis
- UK road support
